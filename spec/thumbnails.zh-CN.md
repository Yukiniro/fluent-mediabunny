# 缩略图

[English（规范原文）](thumbnails.md) | 简体中文

`thumbnail(source, options)` 返回 `Promise<ThumbnailImage | null>`。`thumbnails(source, options)` 返回 `AsyncGenerator<ThumbnailItem>`，每个请求对应一个条目，索引从 0 开始。公开类型见 [types.ts](../src/types.ts)。

两者按共享的[输入契约](conversion.zh-CN.md#输入与探测)读取原始素材，不继承转换 builder 的设置。

## 请求与时间

- `track` 默认使用 Mediabunny 的主视频轨；数值为 `probe()` 返回的视频轨 ID，要求非负安全整数。
- 单张提取必填 `time`。批量提取选择 `times`，或同时提供 `start`、`end`、`count`。
- 时间为有限非负秒数，`-0` 归一化为 0。时间列表包含 1–1000 个非递减值；重复值保留各自位置，不自动排序或去重。
- 区间在微秒取整前后均满足 `end > start`，count 为 1–1000 的整数。第 i 个请求为 `start + i * (end - start) / count`，包含 start、不含 end；count 为 1 时取 start。end 必填，不自动扫描时长。
- 时间原点为 `max(0, input.getFirstTimestamp())`，由所有输入轨道共享。波形数据使用同一原点。查找使用呈现时间戳，适用于 VFR 和 B 帧。
- 查找和覆盖判断按 `Math.round(seconds * 1_000_000)` 转为微秒。请求加原点、帧起点、时长和结束时间均在安全整数范围内；帧时长取整后为正。
- 帧仅覆盖 `[帧起点, 帧起点 + 时长)`。间隙及视频覆盖范围之外返回 `null`，不钳制请求或延长帧。相同帧起点沿用上游查找结果。
- 结果保留请求秒数和源样本的时间戳、时长。`actualTime = sourceTimestamp - timeOriginSeconds`；覆盖零点的帧可以有负 actualTime。

## 图片

| 选项         | 行为                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| `type`       | 默认 JPEG，也支持 PNG                                                  |
| `quality`    | 仅 JPEG，有限值 0–1，默认 0.8；PNG 显式提供此项会失败                  |
| 无尺寸       | 按样本方向修正后的显示尺寸，四舍五入为正整数                           |
| 仅宽或高     | 保持显示比例，另一维取 `max(1, round(...))`                            |
| 同时提供宽高 | 必填 fit，输出严格采用指定尺寸                                         |
| `fit`        | 居中 contain、居中 cover 裁切或 fill 拉伸；必须同时提供宽高            |
| 限制         | 每维为 1–4096 的整数，总面积不超过 16,000,000 像素；允许奇数尺寸及放大 |

先应用源旋转、翻转和像素比例，再按各个样本的几何信息计算尺寸。仅当样本报告方形像素且编码尺寸未变时，回退到轨道像素比例；解码器已修正的栅格不重复应用比例。固定轨道元数据无法补足未暴露的动态像素比例变化。

JPEG 将透明内容和 contain 留白合成到黑底；PNG 保留可用的解码透明度和透明留白。不同浏览器解码器的颜色、原生尺寸可能不同，不保证保留 HDR。生成图片不复制源元数据。

每张结果包含独立持有的非空 Blob、匹配的 MIME 和尺寸，以及轨道 ID 和时间字段。后续请求、取消和清理不影响已返回图片。保存及对象 URL 由应用管理。

## 生命周期

- 单张调用的错误使 Promise 拒绝。批量工厂同步保存并验证选项及完整时间列表，首次 `next()` 才开始媒体 I/O。未启动时调用 `return()` 不进行 I/O。
- 先检查静态选项，再观察预先取消的 signal。有效但已取消的请求以 `ABORTED` 拒绝，不读取素材。
- 各次调用独立持有资源。批次复用一个输入和解码管线，消费者请求下一条目时才编码。封装层最多缓冲一张编码图片及可复用渲染缓冲；消费者保留的结果和原生缓存另计。
- 单个消费者串行调用迭代器。完成、失败、取消、`return()` 和 `for await` 提前 break 都释放资源。提前 break 属于正常结束，不是 `ABORTED`；手动消费时，放弃迭代须等待 `return()`。
- yield 后暂停期间，abort 也会启动清理。下一次 `next()` 拒绝 `ABORTED`；显式 `return()` 等待清理后正常结束。在途操作会被等待，迟到的编码结果被丢弃。
- 样本在图片交付前释放；单张调用和迭代最终完成均等待清理。首个失败优先，后续清理错误附加为诊断；仅清理失败时拒绝 `PROCESSING_FAILED`。
- 成功批次返回所有请求位置，包含空图片。失败终止迭代，不影响已返回结果。提取仅需要所选视频轨的解码器，不执行转换的 AVC 或全文件尺寸预检。

取消没有固定延迟；单张调用成功完成或批次正常结束后，abort 不再生效。

## 错误

错误使用 `MediaError`，阶段为 `preparing` 或 `processing`，不包含文件目标状态。

| 错误码                       | 含义                                           |
| ---------------------------- | ---------------------------------------------- |
| `INVALID_OPTIONS`            | 选项、请求时间、视频轨 ID 或显式尺寸限制无效   |
| `NO_TRACKS`                  | 无主视频轨，或所选视频轨没有编码包             |
| `CODEC_UNAVAILABLE`          | 编码未知或所选轨道无法解码                     |
| `UNSUPPORTED_INPUT`          | 输入或容器不支持，或解码后的时间、几何数据无效 |
| `IMAGE_ENCODING_UNAVAILABLE` | 缺少渲染/编码 API，或输出 MIME 被替换          |
| `OUTPUT_TOO_LARGE`           | 推算或原生尺寸超限，在分配 Canvas 前拒绝       |
| `READ_FAILED`                | 素材读取失败                                   |
| `PROCESSING_FAILED`          | 解码、渲染、空图片编码或清理失败               |
| `ABORTED`                    | 完成前观察到取消                               |

没有帧覆盖请求时间时返回空图片，不作为错误。
